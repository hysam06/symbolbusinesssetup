# Symbol Business Setup

Welcome to the **Symbol Business Setup** website repository! This is a modern, high-performance React application designed to showcase comprehensive business setup services, streamline client inquiries, and establish a strong digital presence.

## 🚀 Features

- **Dynamic Animations:** Built with GSAP and Framer Motion for smooth, engaging user experiences.
- **Responsive Design:** Fully responsive layout optimized for all devices (desktop, tablet, and mobile).
- **Service Showcase:** Detailed pages for various business setup services, ensuring clients have all the information they need.
- **Cloudinary Integration:** Optimized image and media delivery for fast loading speeds.
- **Modern Tech Stack:** Powered by React, Vite, and React Router for fast routing and development.

## 🛠 Tech Stack

- **Framework:** React 19
- **Build Tool:** Vite
- **Routing:** React Router v7
- **Animations:** GSAP & Framer Motion
- **Media Management:** Cloudinary
- **Styling:** CSS (Modular & Responsive)

## 📂 Project Structure

- `src/components/` - Reusable UI components (Hero, Services, Contact, etc.)
- `src/data/` - Static data for services and content
- `src/assets/` - Local assets (images, icons)
- `src/App.jsx` - Main application routing and structure

## 💻 Getting Started

To run this project locally, follow these steps:

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/symbolbusinesssetup.git
   cd symbolbusinesssetup
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Set up Environment Variables:**
   Create a `.env` file in the root directory based on any required configuration (like Cloudinary credentials).

4. **Run the development server:**
   ```bash
   npm run dev
   ```

5. Open your browser and navigate to `http://localhost:5173` to see the application in action.

## 📦 Build for Production

To build the application for production, run:

```bash
npm run build
```

This will generate an optimized build in the `dist/` directory.
